# NikonZR-ELZONE-LUT
An ELZone like exposure monitoring LUT for Nikon ZR in Log3G10 Gamma

Produced according to the Log3G10 specification:  
18% neutral gray corresponds to 33% IRE.  
Pink indicates overexposure/clipping, deep blue reaches the noise floor, and the area between yellow and green represents 18% neutral gray.  
Special thanks to Ed Lachman for proposing the [EL Zone System](https://www.elzonesystem.com).

按照Log3G10规范制作
即，18%中性灰对应33%IRE
粉色过曝，深蓝进底噪，黄绿之间为18%中性灰
