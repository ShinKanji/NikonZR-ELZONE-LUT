# NikonZR-ELZONE-LUT
An ELZone like exposure monitoring LUT for Nikon ZR in Log3G10 Gamma

Produced according to the Log3G10 specification:  
18% neutral gray corresponds to 33% IRE.  
Purple indicates overexposure, deep blue reaches the noise floor, and the area between yellow and green represents 18% neutral gray.  
Special thanks to Ed Lachman for proposing the EL Zone exposure method.[www.elzonesystem.com]
