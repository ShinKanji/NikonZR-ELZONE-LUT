# NikonZR-ELZONE-LUT
An ELZone like exposure monitoring LUT for Nikon ZR in Log3G10 Gamma


Version 2 Changes
V2更新内容

To make the clipping zone more distinguishable,
the overexposed clipping shows BLUE, 
while the underexposed area becomes MAGENTA
为使裁切区域更易于辨识，
过曝部分以蓝色显示，
而欠曝区域则呈现为品红。

---------------
this LUT allows Nikon ZR to have a false color exposure experience

Produced according to the Log3G10 specification:  
18% neutral gray corresponds to 33% IRE.  
Magenta indicates overexposure/clipping, deep blue reaches the noise floor, and the area between yellow and green represents 18% neutral gray.  
Special thanks to Ed Lachman for proposing the [EL Zone System](https://www.elzonesystem.com).

按照Log3G10规范制作
即，18%中性灰对应33%IRE
洋红色过曝，深蓝进底噪，黄绿之间为18%中性灰
感谢Ed Lachman提出的[EL Zone曝光法](https://www.elzonesystem.com).
